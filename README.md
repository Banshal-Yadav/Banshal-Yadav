### what i build

agent-first dev tools and small language models that run on hardware regular people actually own.

### projects

- **[nirCode](https://banshal-yadav.github.io/nirCode-page/)**: agent harness for the terminal, written from scratch in Rust. reads your repo, edits, runs commands, spawns subagents, bring your own model (OpenAI-compatible, Anthropic, Ollama). *(source soon)*
- **[/nir-editor](https://github.com/Banshal-Yadav/nir-editor)**: code editor forked from Zed where the agent actually remembers your project between sessions. open by design, any model, any agent
- **[xlr8](https://github.com/Banshal-Yadav/xlr8)**: instant local github mirror viewer in a single ~5 MB binary. browse commits, search trees, compare diffs up to 4.8× faster than git
- **[maithili-mithi-2b](https://huggingface.co/Bansal123/maithili-mithi-2b)**: Gemma 2B fine-tuned on Maithili, because the language deserves models too
